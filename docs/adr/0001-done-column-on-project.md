# ADR-0001: 完了列の所在を Project の done_column_id とする

## ステータス

承認済み — 2026-05-27

## コンテキスト

カンバンの「完了」ステータスを明示的に表現したい。完了列は1プロジェクトにつき最大1つ。表現方法として2案があった。

- **A: Column に `is_done` フラグを追加する** — カラム自身が完了列かどうかを知る。
- **B: Project に `done_column_id` を追加する** — プロジェクトがどのカラムが完了列かを知る。

## 決定

**B: Project に `done_column_id` を追加する。**

## 理由

- 「1プロジェクトに完了列は1つ」という制約がスキーマレベルで自然に表現できる。A だと複数カラムに `is_done = true` が付く不整合が起こりうる。
- 完了列の変更が Project 側の1フィールド更新で済む。A だと旧列のフラグ解除→新列のフラグ設定の2ステップが必要。
- 完了列が削除された場合は `done_column_id` を `null` に戻すだけでよい。
