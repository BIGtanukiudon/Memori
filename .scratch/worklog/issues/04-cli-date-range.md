# 04. CLI: ローカル日付 → UTC 半開区間の変換

Status: ready-for-agent
依存: なし（純関数のみ。並行実装可）
PRD: `.scratch/worklog/PRD.md` §5

## 目的

日報の日付ずれを防ぐ。**この機能で最もバグりやすい箇所**なので独立させる。

作業ログは UTC で保存される（`2026-08-30T00:15:00.000Z`）が、日報の「今日」は
JST のローカル日付。UTC 文字列の前方一致で絞り込むと
**JST 00:00〜09:00 の記録が毎朝前日に混ざる。**

## 変更対象

- `src-tauri/src/cli/date_range.rs`（新規）
- `src-tauri/src/cli/mod.rs`（モジュール登録）

`chrono` は `features = ["clock"]` で導入済みなので `chrono::Local` が使える。

## 仕様

```rust
/// ローカル日付 from..=to を UTC の半開区間 [start, end) に変換する。
/// 返り値は既存 now_iso() と同じ RFC3339 / ミリ秒 / UTC 表記。
pub fn local_date_range_to_utc(from: &str, to: &str) -> Result<(String, String), String>
```

- 入力は `YYYY-MM-DD`。不正な形式・存在しない日付はエラー文字列を返す
- `from > to` はエラー
- `to` は**その日の終わりまで含む**ため、内部で `to + 1日` の 00:00 をとる（半開区間）
- 「今日」を返すヘルパ `today_local()` も用意する

## テスト観点（TDD）

- `2026-08-30`〜`2026-08-30`（JST）→ `2026-08-29T15:00:00.000Z` 以上
  `2026-08-30T15:00:00.000Z` 未満
- 複数日指定が正しい範囲になる
- 月末・年末をまたぐ指定（`2026-12-31`）
- うるう日（`2028-02-29`）
- 不正形式 `2026-8-30` / `2026-13-01` / `2026-02-30` がエラー
- `from > to` がエラー

タイムゾーン依存のテストは実行環境の TZ に左右されるため、
オフセットを引数で渡せる内部関数に分けて検証する（`Local` 直参照はテスト不能）。
